# Glossário

## Zootecnia e raça

| Termo | Significado |
|---|---|
| **Nelore PO** | Puro de Origem: animal com registro genealógico definitivo na ABCZ |
| **CEIP** | Certificado Especial de Identificação e Produção (MAPA): concedido aos animais de melhor desempenho dentro de programas de melhoramento genético |
| **RGN / RGD** | Registro Genealógico de Nascimento / Definitivo (ABCZ) |
| **ABCZ** | Associação Brasileira dos Criadores de Zebu |
| **PMGZ** | Programa de Melhoramento Genético de Zebuínos (ABCZ) |
| **ANCP** | Associação Nacional de Criadores e Pesquisadores |
| **DEP** | Diferença Esperada na Progênie: estimativa do valor genético transmitido aos filhos |
| **DECA** | Classe de percentil do animal no programa (1 = melhores 10%) |
| **EPMURAS** | Avaliação visual: Estrutura, Precocidade, Musculosidade, Umbigo, Raça, Aprumos, Sexualidade |
| **ECC** | Escore de Condição Corporal (reserva de gordura) |
| **Frame score** | Escore de tamanho/estrutura baseado na altura de garupa e na idade |
| **GMD** | Ganho Médio Diário (kg/dia) |
| **Garrote** | Macho jovem, após a desmama e antes da idade adulta |
| **Matriz** | Fêmea de reprodução |
| **Cupim** | Giba muscular sobre a cernelha dos zebuínos |
| **Cernelha** | Ponto mais alto do dorso, entre as escápulas (nos zebuínos, logo atrás do cupim) |
| **Ílio (anca)** | Ponta óssea da frente da garupa |
| **Ísquio** | Ponta óssea de trás da garupa (ponta da nádega) |
| **Aprumos** | Conformação e posicionamento dos membros |
| **Perímetro escrotal (PE)** | Circunferência do escroto, ligada à fertilidade e à precocidade sexual |
| **STAY** | Habilidade de permanência: probabilidade de a vaca continuar parindo até certa idade |
| **PP30** | Probabilidade de prenhez precoce (até 30 meses) |
| **IPP** | Idade ao Primeiro Parto |
| **MP120** | Habilidade materna medida pelo peso do bezerro aos 120 dias |
| **AOL / ACAB** | Área de olho de lombo / acabamento de gordura (carcaça, por ultrassom) |
| **IATF** | Inseminação Artificial em Tempo Fixo |

## Técnico

| Termo | Significado |
|---|---|
| **PWA** | Progressive Web App: site instalável que funciona offline |
| **Segmentação** | Separar os pixels do animal do fundo (máscara) |
| **Keypoints** | Pontos anatômicos localizados na imagem |
| **ArUco** | Marcador quadrado impresso, fácil de detectar, usado para calibrar a escala |
| **Homografia** | Transformação que corrige a perspectiva de um plano |
| **Caixa virtual** | Paralelepípedo C × P × L que envolve o tronco do animal |
| **IPL** | Índice de Preenchimento Lateral: área da silhueta ÷ área da caixa |
| **MAPE** | Erro percentual absoluto médio |
| **PCK** | Percentage of Correct Keypoints: métrica de acerto dos pontos |
| **Active learning** | O modelo sugere, o humano corrige e a correção vira treino |
